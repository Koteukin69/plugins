# Koteukin69/templates.nvim

Моя реализация сложных расширяемых шаблонов для Neovim

## Установка

Через [lazy.nvim](https://github.com/folke/lazy.nvim):

```lua
{
  "Koteukin69/templates.nvim",
  opts = {
    keyword = "<leader>m" -- Начало keyword для вызова шаблонов
    templates_path = "~/.config/nvim/templates/snippets" -- Путь к шаблонам
    components_path = "~/.config/nvim/templates/components/" -- Путь к компонентам
    modules_path = "~/.config/nvim/templates/modules/" -- Путь к модулям
  }
}
```

## Основное

- Шаблоны - данные, которые вставляются при вызове макроса, он не содержит в себе никакой логики, но может вызывать модули.
- Компоненты - простые lua функции, вызываемые в шаблонах при их вставке. Позволяют менять контент в шаблоне.
- Модули - lua функции, вызываемые в шаблонах подобно компонентам. Позволяют влиять напрямую на ide.

## Шаблоны

Шаблон представляет из себя макрос

Шаблон позволяет вставлять сложные структуры кода

Контент в шаблонах может менятся с помощью компоненов.

При этом шаблоны позволяют непосредственно влиять на редактор кода с помощью модулей.

## Модули

Модуль - это lua функция, которая вызывается при использовании шаблона, в котором она находится.

Модуль получает на вход:

- Имя файла
- Место модуля в файле

Модуль может вызывать lua функции непосредственно связанные с nvim

Если модуль что-то возвращает, он заменяет себя в шаблоне вместе с телом. Иначе тело модуля остаётся.

## Структура

Шаблоны представляют собой структуру в файловой системе, позволяющая указать условие вызова шаблона:

```
*.[jt]s{,x} -> папка является фильтром по имени файла
  f.snip    -> имя шаблона фильтр по
  v.snip
```
